# Twig Analysis
A PGA Tour tournament prediction model that combines strokes-gained regression with Monte Carlo simulation to generate probabilistic outcome forecasts. The system converts raw player performance data from the Data Golf API into calibrated predictions for wins, top finishes, cut lines, and expected finishing positions.

# Why Twig?
As a current twig myself, it only seemed fit to name the project after the twiggiest twigs all of them all, tour card carrying slotted weapons like the ones we are evaluating. 

# Efficiency
Golf is mostly noise. 15% (at most) of round-level scoring can be consistently predicted (at best). Guys get on putting streaks, weather plays a factor, luck is involved in almost every shot. This is a modest attempt at predicting the most unpredictable sport. 

# Next Step
Try to add course-specific data to improve the model. Some courses favor driving accuracy, while some other ones require high iron accuracy from longer distances (175-215 yards).
